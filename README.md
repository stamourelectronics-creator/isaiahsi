isaiahsi 7.0

## AI previews

The release assistant, Programmer Preview, and Image Studio use Puter.js directly in the browser. Visitors can ask general questions, try coding prompts, generate images, edit an uploaded photo, view generated results, and ask questions about an uploaded photo. The assistant uses the confirmed IsaiahSI release information and avoids inventing unannounced details.

No site-owned API key or backend is required. Puter may ask visitors to sign in or approve usage. Image prompts and selected photos are sent to Puter when visitors use the image tools; avoid sensitive information.
